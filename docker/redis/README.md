# Redis

Stack Redis gồm `redis`, `redis-commander`.

## Start

```bash
bash docker/redis/start.sh
```

Hoặc từ thư mục gốc:

```bash
docker compose up -d redis redis-commander
```

## Connection

- Host: `localhost:6379`
- Password: `redis123`
- UI: http://localhost:8081
